🔄 Chuyển file HTML thành nội dung

← Về danh sách bài viết

Dán mã HTML hoặc chọn file .html. Công cụ chuyển sang cú pháp ô Nội dung để bạn sao chép vào bài viết.

File chỉ được đọc trên máy bạn, không tải lên server. Lý do nên dùng ô Nội dung thay vì nhúng file: nội dung trong <iframe> được Google coi là tài liệu riêng, không tính cho trang bài viết.
