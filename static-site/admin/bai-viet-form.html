Mỗi đoạn cách nhau bằng dòng trống. Dòng VIẾT HOA = tiêu đề lớn. Dòng bắt đầu bằng "- " hoặc "• " = danh sách. Dòng "1. " = danh sách số. Ảnh: ![chú thích](url)

Cú pháp nâng cao (mục lục, FAQ, khung gợi ý, CTA, bảng giá...)
  • [toc] — chèn mục lục tự động từ các dòng VIẾT HOA trong bài.
  • :::tip ... ::: — khung "mẹo hay" nổi bật.
  • :::faq ... ::: — mỗi câu hỏi 1 dòng Q: ..., câu trả lời dòng A: ... ngay sau.
  • :::cta ... ::: — dòng đầu là tiêu đề, dòng giữa là mô tả, dòng [Tên nút](link) là nút bấm.
  • :::grid ... ::: — mỗi dòng Nhãn | Giá trị thành 1 ô trong lưới.
  • Dán nguyên 1 đoạn mã HTML (bắt đầu bằng <) cũng được — hệ thống sẽ tự lọc bỏ phần nguy hiểm (script, style...) trước khi hiển thị.

Tải lên 1 file .html hoàn chỉnh (có CSS/hình vẽ riêng) — nội dung file sẽ hiển thị y nguyên bản gốc bên trong khung bài viết, vẫn giữ menu/footer của site như bài viết bình thường. Để trống nếu dùng ô "Nội dung" phía trên.
